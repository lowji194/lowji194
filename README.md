## About

I design and build practical software tools focused on workflow automation, Chromium Manifest V3 extensions, Windows desktop utilities, and self-hosted infrastructure.

- **Building:** Secure MCP servers (`serverops-mcp`), Windows desktop utilities (`codex-session-manager`), and privacy-first browser extensions (`Extension-ProxyFlow`, `Extension-Cookie-Manager`)
- **Core Stack:** TypeScript, Python, JavaScript (Node.js / Express / Next.js), C# (.NET), PowerShell, and Bash
- **Focus Areas:** Workflow automation, OAuth 2.1 & local-first security, API gateways, and Linux server operations
- **Location:** Từ Sơn, Bắc Ninh, Vietnam
